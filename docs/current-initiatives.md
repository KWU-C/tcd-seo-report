## アーカイブページのcanonical・URL整合性改善

- 対象: 一覧系（アーカイブ）ページ全般。Works の一覧とカテゴリ（/works、/works/{カテゴリ}）、/branding とタグ一覧、/service、/about、/recruit、著者ページ（/branding/author/{名前}）、各ページの2ページ目以降、404ページ。サイト全体のヘッダー・フッター・一覧ナビの内部リンク
- 状態: 実装済み・効果確認待ち
- 実装日: 2026-10-19
- 評価予定日: 2026-11-02（14日）／2026-11-16（28日）
- 仮説: 一覧系ページの canonical を、実際に200を返すスラッシュなしのURLに揃え、内部リンクの301をなくすことで、Google が選ぶ代表URLと canonical・サイトマップ・内部リンクが一致し、代表URLの分散と不要なクロールが減る
- 成功シグナル: 一覧系ページの表示回数がスラッシュなしのURLに集約され、合計のクリック・表示回数が横ばい〜改善する。/about の社名クエリ（「株式会社tcd」など）の掲載順位が下がらない
- メモ: tcd-2026-theme PR #20（e324a93・8d1ac01）。同日に PR #21（/works/corporate 上部の導入文の削除、c4b1eff）もあわせて本番反映。記録: docs/research/archive-canonical-fix-2026-10-19.md

### 変更内容（すべて2026-10-19）

| 対象 | 変更前 | 変更後 |
|---|---|---|
| 一覧系ページの canonical・og:url | 末尾スラッシュあり（そのURLは301でスラッシュなしへ転送） | スラッシュなし（200） |
| 404ページ | canonical・og:url を出力 | 出力しない |
| 旧著者URL（/author/{名前}、/branding/{名前}） | 301が2回 | 301が1回で /branding/author/{名前} へ |
