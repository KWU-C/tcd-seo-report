# 問い合わせ集計シートに追加する「フォーム区分」の列（2026-11-16）

週次レポート②に「フォーム区分（一般／BtoB／不明）」と「案件相談率」を加えた。
フォーム区分は Dot が集計シート（タブ `weekly`）に記録する。**既存の13列と、その値の意味は変えない。**

## 追加する列（N列以降。列名で読むので順番は問わない）

| 列名 | 内容 |
|---|---|
| `form_general` | 一般問い合わせ（`general_total`）のうち、一般フォーム（/contact）から送られたもの |
| `form_b2b` | 同、BtoBフォーム（/b2b/contact）から送られたもの |
| `form_unknown` | 同、どちらのフォームか分からないもの |
| `consultation_form_general` | 案件相談（`project_consultation`）のうち、一般フォームから |
| `consultation_form_b2b` | 同、BtoBフォームから |
| `consultation_form_unknown` | 同、分からないもの |

## 記入のルール（レポート生成時に検査する）

- 6列とも空欄なら「未記録」と表示する（0件とは扱わない）。過去の週は空欄のままでよい。
- 1列でも記入する週は、6列すべてに0以上の整数を記入する。
- `form_general + form_b2b + form_unknown = general_total`、
  `consultation_form_general + consultation_form_b2b + consultation_form_unknown = project_consultation` になること。
- 合わない場合も、②の既存の件数（一般問い合わせ・案件相談など）はそのまま使う。フォーム区分だけを「不整合」と表示し、担当者に通知する。

## Dot に確認すること（記入を始める前に）

1. **BtoBフォーム（/b2b/contact）からの送信を、いまの `general_total` に含めているか。**
   フォーム区分は `general_total` の内訳として設計した。含めていない場合は、BtoB の送信を一般問い合わせに含めるかどうか（含めると、過去の週と件数の基準が変わる）を決めてから記入を始める。
2. 通知メールから送信元のフォームを判別できるか（件名・本文・送信元アドレスなど）。判別できないものは `form_unknown` に入れる。

## 案件相談率

- 案件相談 ÷ 一般問い合わせ（当週、直近4週累計）。一般問い合わせが0件の週は計算しない。
- 4週累計は、対象の4週がすべて確定している場合だけ表示する（既存の累計と同じ扱い）。
